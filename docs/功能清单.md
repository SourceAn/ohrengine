# OhEngine 功能清单

> 生成时间：2026-08-28（基于当前工作区源码逐项核验）。
> 状态图例：✅ 已完成可用 · 🟡 部分完成/受限 · ⬜ 占位/未实现。
> 注：`docs/status.md`（2026-08-18）为早期审计，部分结论已过时（如 PDF 现已支持文本层提取、阅读器 UI 已模块化为 `ohrengine-reader`），以本清单为准。

---

## 一、文件格式支持

| 功能 | 状态 | 说明 |
|------|------|------|
| EPUB 2.0.1 / 3.2 / 3.3 解析 | ✅ | container→OPF→manifest→spine→NCX/nav→封面，MIME 猜测 |
| EPUB 目录（NCX/SMIL） | ✅ | 目录树 + 媒体叠加控制 |
| TXT 解析 | ✅ | 大文件分块流式 UTF-8 解码，空行分章 |
| CBZ 解析 | ✅ | SecureArchive 安全解压 + 图片过滤 + 自然排序 |
| CBR（RAR） | ⬜ | Debug 书架占位按钮，点击仅弹 Toast，无解析 |
| PDF（文本层提取→可重排） | ✅ | PdfParser 自包含扫描对象树、FlateDecode、ToUnicode CMap、Tj/TJ 文本提取，产出 REFLOW 章节 |
| PDF（扫描版/纯图像） | ⬜ | 无文本层，无法提取文本 |
| PDF（`ohrengine-reader` 宿主内） | 🟡 | 可复用阅读器按约束仅支持 EPUB/TXT，明确拒绝 .pdf 并提示 |
| 安全解压 | ✅ | 路径穿越/符号链接/条目数/总大小上限校验 |
| 解析/策略注册表 | ✅ | ParserRegistry（扩展名+目录探测）、StrategyRegistry（Reflow/Image） |
| 格式白名单裁剪 | ✅ | ParserRegistry 支持 `setEnabledFormats`，宿主可只开 EPUB/TXT |

## 二、HTML / CSS 排版渲染

| 功能 | 状态 | 说明 |
|------|------|------|
| HTML→DOM | ✅ | 含 math/svg/table/ruby/float 语义节点检测 |
| CSS 解析/编译/选择器 | ✅ | @media、@font-face、@import（含远程）、RuleIndex 匹配 |
| 媒体查询 | ✅ | prefers-contrast / reduced-motion / color-gamut |
| 字体加载/回退 | ✅ | @font-face 注册 + Unicode 分段回退缓存 |
| 块级/行内布局、断行、分页 | ✅ | CJK+拉丁断词、标点挤压、orphan/widow/avoidBreakInside |
| 两端对齐 | ✅ | 含标点挤压 |
| Flex / Float / 列表 | ✅ | 尺寸约束、浮动环绕、列表测宽 |
| Ruby / 仿粗斜体 | ✅ | 渲染辅助 |
| SVG 渲染 | ✅ | rect/circle/path/text 等 |
| MathML 渲染 | ✅ | fraction/radical/上下标/text |
| 表格布局 | 🟡 | 列/跨行跨列/行高/分页/边框/文本齐全；**单元格内图片仅渲染 `[img] path` 占位文本** |
| 远程资源加载 | ✅ | HTTPS + 超时 + 响应体上限 + 取消令牌 |
| CFI 定位 | 🟡 | 近似实现：章节号+段落索引做字符偏移估算 |
